# OpenCode Watchdog

OpenCode Watchdog is a local circuit breaker for runaway OpenCode sessions. It provides the `ocw` command and is designed to inspect local session streams. The repository currently marks the package private; remove that flag and confirm build/test behavior before publishing.

- **Version in repository:** `0.1.0`
- **License:** MIT
- **Source:** [GitHub](https://github.com/M4G3LL4N0/opencode-watchdog)
- **Project site:** [https://opencode-watchdog.vercel.app](https://opencode-watchdog.vercel.app)

## Installation

The command below is the intended npm installation form; it is not evidence that this distribution has been published yet.

```sh
npm install --global opencode-watchdog
```



## First commands

```sh
ocw --help
ocw simulate
```
