# Contributing to OpenCode Watchdog

Thank you for considering contributing to OpenCode Watchdog! Please read our [Code of Conduct](CODE_OF_CONDUCT.md) to keep our community approachable and respectful.

## How to Contribute

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Create a branch for your feature or fix.
4. Make your changes.
5. Ensure the test suite passes.
6. Submit a pull request.
